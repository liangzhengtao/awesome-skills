# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-15

### Added

#### 📝 Academic Writing Skills
- **`latex-paper`** — LaTeX paper writing with journal-specific formatting (IEEE, ACM, Springer, Nature, Science)
- **`research-proposal`** — Grant and thesis proposal writing with structured templates
- **`literature-review`** — Systematic literature review with PRISMA-style methodology
- **`academic-english`** — Academic English polishing for non-native speakers

#### 📊 Data Analysis Skills
- **`statistical-analysis`** — Statistical testing with assumption checks, effect sizes, and confidence intervals
- **`data-visualization`** — Publication-quality figures using matplotlib, seaborn, and plotly
- **`ml-experiment`** — ML experiment tracking with proper baselines, ablation studies, and reproducibility

#### 📖 Literature Management Skills
- **`zotero-integration`** — Zotero bibliography integration and management
- **`citation-management`** — Citation formatting across styles (APA, IEEE, Nature, Chicago, MLA)

#### 🔬 Experiment Tools
- **`jupyter-notebook`** — Clean Jupyter notebook workflows with best practices
- **`docker-reproducibility`** — Reproducible research environments with Docker

#### 📬 Paper Submission
- **`conference-submission`** — Conference submission checklist for NeurIPS, ICML, CVPR, ACL, AAAI

#### 🛠 Infrastructure
- Bilingual README (English + Chinese)
- GitHub CI workflow for skill validation
- Issue template for requesting new skills
- Pull request template for contributing skills
- Contributing guide with skill template
- Code of Conduct (Contributor Covenant 2.0)
- Security policy
- Example research workflow combining multiple skills
