### 💡 ما هذا؟

**Awesome Skills** هي مجموعة منتقاة من [مهارات مساعد الترميز بالذكاء الاصطناعي](https://kimi.ai) — ملفات تعليمات قابلة لإعادة الاستخدام تُعلّم مساعدك الذكي كيفية أداء المهام البحثية *بالضبط* كما تريده.

بدلاً من كتابة نفس الموجه مراراً وتكراراً، تكتب **مهارة مرة واحدة** — ويتبعها مساعدك الذكي بشكل مثالي في كل مرة.

### 🚀 البدء السريع

المهارات هي مجرد **ملفات تعليمات** تُخبر مساعدك الذكي كيف يتصرف. ضعها في مشروعك وسيتبع التعليمات تلقائياً.

#### Cursor (.cursorrules)

```bash
# انسخ المهارة إلى جذر مشروعك
cp skills/latex-paper.md .cursorrules

# أو أضفها إلى القواعد الموجودة
cat skills/latex-paper.md >> .cursorrules
```

#### Claude Code (CLAUDE.md)

```bash
# انسخ المهارة إلى جذر مشروعك
cp skills/latex-paper.md CLAUDE.md

# أو أضفها إلى التعليمات الموجودة
cat skills/latex-paper.md >> CLAUDE.md
```

#### Kimi Code (AGENTS.md)

```bash
# انسخ المهارة إلى جذر مشروعك
cp skills/latex-paper.md AGENTS.md

# أو أضفها إلى التعليمات الموجودة
cat skills/latex-paper.md >> AGENTS.md
```

> 💡 **نصيحة احترافية:** يمكنك دمج عدة مهارات عن طريق إلحاقها في ملف واحد!

### 🎬 أمثلة الاستخدام

#### مثال 1: كتابة ورقة كاملة

```bash
# 1. حمّل مهارة latex-paper
cp skills/latex-paper.md CLAUDE.md

# 2. اسأل مساعدك الذكي
"Write a LaTeX paper for IEEE TPAMI on my transformer attention mechanism.
Include: abstract, introduction, related work, method, experiments, conclusion.
Use IEEE citation format. Reference figures as Fig. 1, Fig. 2, etc."
```

#### مثال 2: تحليل بيانات التجارب

```bash
# 1. حمّل مهارة statistical-analysis
cp skills/statistical-analysis.md .cursorrules

# 2. اسأل مساعدك الذكي
"Analyze the data in results.csv. Compare model A vs model B performance.
Check normality, run appropriate tests, report effect sizes and CIs.
Generate a box plot for Figure 1."
```

#### مثال 3: سير عمل بحثي متكامل

راجع [`examples/research-workflow.md`](examples/research-workflow.md) لسير عمل كامل من البداية إلى النهاية يجمع عدة مهارات.

<details>
<summary><b>س: مع أي مساعدي ذكاء اصطناعي تعمل هذه المهارات؟</b></summary>

تعمل هذه المهارات مع أي مساعد ترميز ذكي يدعم التعليمات المخصصة:
- [Cursor](https://cursor.sh) عبر `.cursorrules`
- [Claude Code](https://claude.ai/code) عبر `CLAUDE.md`
- [Kimi Code](https://kimi.ai) عبر `AGENTS.md`
- [Windsurf](https://windsurf.ai) عبر `.windsurfrules`
- [Cline](https://github.com/cline/cline) عبر `.clinerules`
- [Aider](https://aider.chat) عبر `.aider.conf.yml`
- أي مساعد يقرأ ملفات التعليمات

</details>

<details>
<summary><b>س: هل يمكنني دمج عدة مهارات؟</b></summary>

نعم! ببساطة قم بإلحاق ملفات المهارات:

```bash
cat skills/latex-paper.md skills/data-visualization.md > CLAUDE.md
```

أو استخدمها بشكل انتقائي بناءً على مهمتك الحالية.

</details>

<details>
<summary><b>س: كيف تختلف هذه المهارات عن كتابة الموجهات فحسب؟</b></summary>

المهارات:
- **دائمة** — محفوظة في مشروعك، لا تُفقد بين الجلسات
- **تحت إصدار** — تتبع التغييرات مع git
- **قابلة لإعادة الاستخدام** — شاركها مع فريقك
- **قابلة للدمج** — ادمج عدة مهارات
- **مُجرَّبة** — مُحسَّنة من خلال سير العمل البحثي الفعلي

</details>

<details>
<summary><b>س: هل يمكنني تعديل المهارات لمجالي؟</b></summary>

بالتأكيد! المهارات هي مجرد ملفات markdown. انسخ هذا المستودع وخصّصه لمجالك البحثي المتخصص، أو متطلبات مجلتك، أو اتفاقيات مختبرك.

</details>

<details>
<summary><b>س: هل تعمل هذه المهارات للأوراق غير الإنجليزية؟</b></summary>

نعم! يمكن تكوين مهارات مثل `latex-paper` و`academic-english` للصينية (中文) واليابانية (日本語) ولغات أخرى. راجع توثيق كل مهارة لخيارات اللغة.
