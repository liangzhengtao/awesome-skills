# Skills Directory

Place your skill files here. Each skill is a markdown file that teaches your AI assistant how to perform a specific research task.

## Naming Convention

- Use lowercase with hyphens: `my-skill-name.md`
- Be descriptive: `statistical-analysis.md` not `stats.md`

## Required Sections

Every skill file must include:

1. `# Skill Name`
2. `## Description`
3. `## Instructions`
4. `## Examples`
5. `## Configuration` (optional)
6. `## Notes` (optional)

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the full template.
