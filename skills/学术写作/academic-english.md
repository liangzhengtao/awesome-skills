# 学术英语写作

> Category: 学术写作 | Difficulty: beginner | Last updated: 2026

## When to Use

当用户需要改善学术英语写作质量时使用此技能。适用于非英语母语者的论文润色、语法修正、表达优化、写作风格指导等场景。当用户提及学术英语、academic English、论文润色、grammar check、学术写作表达、English writing improvement 或 writing style 时触发。

## Instructions for AI Assistant

### 基本原则

1. **正式性**：学术写作要求正式语体，避免口语化表达
2. **精确性**：用词准确，避免歧义
3. **客观性**：减少主观色彩，使用证据支撑
4. **简洁性**：表达简明，避免冗余
5. **一致性**：术语、时态、人称保持一致

### 学术语气调节

#### Hedging（弱化语气）

学术写作中适当使用弱化语气表达谨慎态度：

```markdown
## Hedging 表达

### Modal Verbs
- may / might / could: "This **may** explain the observed phenomenon."
- would: "This **would** suggest a causal relationship."

### Adverbs
- possibly / potentially: "This **potentially** indicates..."
- presumably: "The model **presumably** learns..."
- apparently: "The results **apparently** contradict..."

### Phrases
- It appears that...: "**It appears that** the method generalizes well."
- It seems likely that...: "**It seems likely that** overfitting occurred."
- There is evidence to suggest...: "**There is evidence to suggest** a correlation."
- To some extent / In part: "The improvement is, **to some extent**, attributable to..."

### Verbs
- suggest / indicate / imply: "Our findings **suggest** a new direction."
- tend to: "Models **tend to** overfit on small datasets."
- appear to: "The loss **appears to** converge after epoch 50."
```

#### Boosting（加强语气）

有充分证据支持时可使用强化表达：

```markdown
## Boosting 表达

### 强动词
- demonstrate / establish / confirm: "Our experiments **demonstrate** that..."
- reveal / uncover: "The analysis **reveals** a fundamental limitation."

### 强副词
- clearly / obviously / evidently: "The results **clearly** show..."
- significantly / substantially: "Performance **substantially** improved."
- consistently / invariably: "The pattern **consistently** emerges across..."

### 强句式
- It is well established that...
- There is compelling evidence that...
- These findings unambiguously show...
```

#### 使用原则

```
何时使用 Hedging:
  - 讨论结果的解释（interpretation）
  - 提出假设或推测（speculation）
  - 指出局限性（limitation）
  - 推广到未验证的场景

何时使用 Boosting:
  - 报告自己的实验结果（own results）
  - 引用已确立的理论（established facts）
  - 陈述主要贡献（key contributions）

示例对比：
  Hedging:  "These results **may suggest** that the model learns transferable features."
  Boosting: "Our experiments **clearly demonstrate** a 15% improvement over the baseline."
```

### 常见语法错误

#### 1. 主谓一致

```markdown
❌ "The results of the experiment **shows** that..."
✅ "The results of the experiment **show** that..."

❌ "Each of the models **were** evaluated."
✅ "Each of the models **was** evaluated."

❌ "Neither the model nor the baselines **was** effective."
✅ "Neither the model nor the baselines **were** effective."

规则：
- 主语是 "the results"（复数）→ show
- "Each of + 复数名词" → 单数动词
- "Neither A nor B" → 动词与 B 一致
```

#### 2. 冠词使用

```markdown
❌ "We proposed **a** novel method for **the** image classification."
✅ "We proposed **a** novel method for image classification."

❌ "**The** deep learning has shown..."
✅ "Deep learning has shown..." (泛指不加 the)

❌ "We use **the** CNN to extract features."
✅ "We use **a** CNN to extract features." (首次提及用 a)

规则：
  - 泛指概念 → 不加 the: "Deep learning is..."
  - 特指某个 → 加 the: "The deep learning framework proposed by..."
  - 首次提及 → 用 a/an: "We propose a novel approach..."
  - 再次提及 → 用 the: "The approach is evaluated on..."
  - 缩写首字母辅音 → a: "a CNN", "a GAN"
  - 缩写首字母元音 → an: "an RNN", "an LSTM"
```

#### 3. 时态一致性

```markdown
## 时态使用规范

### Abstract
- 过去时（描述做了什么）: "We **proposed** a novel method..."
- 现在时（陈述结论）: "The results **show** that..."

### Introduction
- 现在时（普遍事实）: "Deep learning **has** become..."
- 现在完成时（近期进展）: "Researchers **have proposed**..."
- 过去时（特定研究）: "Smith et al. **proposed**..."

### Methodology
- 过去时（描述自己的方法）: "We **employed** a CNN..."
- 现在时（描述图表/算法）: "Figure 1 **shows**..."

### Results
- 过去时（报告结果）: "The model **achieved** 95% accuracy."
- 现在时（讨论含义）: "This **suggests** that..."

### Related Work
- 过去时或现在完成时:
  "Author et al. **proposed** / **have proposed**..."
```

#### 4. 平行结构

```markdown
❌ "The model can extract features, classifying images, and
    makes predictions."
✅ "The model can **extract** features, **classify** images,
    and **make** predictions."

❌ "The method is effective, efficient, and has scalability."
✅ "The method is **effective**, **efficient**, and **scalable**."

规则：并列的成分必须使用相同的语法形式
```

#### 5. 常见错误汇总

```markdown
❌ "different than"    → ✅ "different from"
❌ "compare to"        → ✅ "compare with" (比较相似性)
                         "compare to" (比喻)
❌ "regardless about"  → ✅ "regardless of"
❌ "discuss about"     → ✅ "discuss" (不加 about)
❌ "emphasize on"      → ✅ "emphasize" (不加 on)
❌ "researches" (复数)  → ✅ "research" (不可数)
❌ "informations"      → ✅ "information" (不可数)
❌ "equipments"        → ✅ "equipment" (不可数)
❌ "literatures"       → ✅ "literature" (不可数)
❌ "evidences"         → ✅ "evidence" (不可数)
```

### 段落结构

#### TEEL 模型

```markdown
**T**opic Sentence（主题句）:
  本段的核心论点，通常放在段首。

**E**vidence（证据）:
  支撑论点的数据、引用或实验结果。

**E**xplanation（解释）:
  分析证据如何支持论点，为什么重要。

**L**ink（连接）:
  与下一段或整体论点的衔接。
```

#### 示例段落

```markdown
[Topic] Federated learning has emerged as a promising paradigm for
privacy-preserving machine learning in healthcare settings. [Evidence]
Recent studies have demonstrated its applicability in clinical prediction
tasks, achieving comparable performance to centralized approaches while
keeping patient data within individual institutions (Smith et al., 2024;
Zhang et al., 2025). [Explanation] This is particularly significant in
the medical domain, where strict regulations such as HIPAA and GDPR
impose severe restrictions on data sharing across organizational
boundaries. By enabling collaborative model training without raw data
exchange, federated learning addresses both regulatory compliance and
patient privacy concerns. [Link] However, several challenges remain,
particularly regarding communication efficiency and model heterogeneity,
which we discuss in the following section.
```

### 摘要写作公式

#### 结构化摘要（Structured Abstract）

```markdown
**Background**: [1-2句] 领域背景和待解决的问题。

**Objective**: [1句] 本研究的具体目标。

**Methods**: [2-3句] 采用的主要方法和技术。

**Results**: [2-3句] 关键实验结果和数据。

**Conclusions**: [1-2句] 主要结论和意义。
```

#### 自由格式摘要（Free-form Abstract）

```
公式：[背景] + [问题] + [方法] + [结果] + [贡献]

第一句（背景）：[领域] has witnessed significant progress in [方面].
第二句（问题）：However, existing approaches suffer from [问题].
第三句（方法）：In this paper, we propose [方法名称], which [核心思想].
第四句（方法细节）：Specifically, our approach [技术要点].
第五句（结果）：Extensive experiments on [数据集] demonstrate that [方法]
               achieves [具体结果], outperforming [基线] by [幅度].
第六句（贡献）：Our contributions include [贡献列表].
```

#### 摘要示例

```markdown
Deep learning has achieved remarkable success in medical image analysis.
However, existing methods require large amounts of labeled data, which
is expensive and time-consuming to obtain in clinical settings. In this
paper, we propose MedCLIP, a contrastive learning framework that
leverages both image and text reports for pre-training medical image
encoders without manual annotations. Specifically, our approach aligns
radiology images with their corresponding reports through a dual-encoder
architecture with cross-modal contrastive loss. Extensive experiments on
four downstream tasks across six datasets demonstrate that MedCLIP
achieves an average improvement of 5.3% over supervised baselines when
fine-tuned with only 10% labeled data. Our approach establishes a new
paradigm for label-efficient medical image analysis.
```

```markdown
## 动词 + that 从句
- demonstrate that / show that / indicate that

## 动词 + 宾语 + as
- define X as / describe X as / characterize X as

## 动词 + 宾语 + to-infinitive
- enable X to / allow X to / cause X to
- require X to / encourage X to / prompt X to

## 动词 + 动名词
- involve doing / entail doing / require doing
- consider doing / avoid doing / recommend doing
```

## Templates

### 段落润色模板（Before → After）

```markdown
**Before (口语化):**
In this paper, we got better results than other methods. Our method
works well and is pretty fast. We think this is because of the new
attention mechanism.

**After (学术化):**
In this paper, our approach achieved superior results compared to
existing methods. The proposed method demonstrates both effectiveness
and computational efficiency. We hypothesize that this improvement
is attributable to the novel attention mechanism.
```

## Common Patterns

### 润色检查清单

```markdown
## Self-Editing Checklist

### Clarity (清晰度)
- [ ] 每段有明确的主题句
- [ ] 每句话只有一个主要观点
- [ ] 避免过长的句子（>30词考虑拆分）
- [ ] 代词指代清晰（this/that/it 明确指向）

### Conciseness (简洁性)
- [ ] 删除冗余表达 ("in order to" → "to")
- [ ] 避免空洞短语 ("It is important to note that" → 删除)
- [ ] 减少 there is/are 句型
- [ ] 使用主动语态优先

### Precision (精确性)
- [ ] 术语使用一致
- [ ] 数据有具体数字支撑
- [ ] 避免模糊词（very, quite, rather）
- [ ] 缩写首次出现有全称

### Flow (流畅性)
- [ ] 段落间有过渡连接
- [ ] 句式长短交替
- [ ] 信息从已知到新知排列
- [ ] 平行结构正确
```

### 冗余表达优化

```markdown
冗余 → 简洁

"due to the fact that"     → "because"
"in order to"              → "to"
"at this point in time"    → "currently / now"
"it is worth noting that"  → 删除，直接说
"the majority of"          → "most"
"a large number of"        → "many"
"in the event that"        → "if"
"with regard to"           → "regarding / about"
"on a regular basis"       → "regularly"
"has the ability to"       → "can"
"makes use of"             → "uses"
"give rise to"             → "cause"
"take into consideration"  → "consider"
"it can be seen that"      → 删除，直接说结果
```

## Pitfalls to Avoid

1. **过度使用被动语态**：学术写作接受被动语态，但过多会影响可读性，主动/被动比例建议 7:3
2. **Chinglish 表达**：避免直译中文习惯（如 "with the development of..." 用得过多）
3. **过度弱化**：适度使用 hedging，不要让每句话都变成 "It might perhaps possibly..."
4. **术语不一致**：同一概念全文使用同一术语，建立术语表
5. **引用形式化**："According to [1]" 不如 "Smith et al. (2024) demonstrated..."
6. **过度使用 furthermore/moreover**：变换使用不同的过渡词
7. **首字母缩写过多**：仅对高频使用的术语定义缩写
8. **时态混乱**：严格按规范使用时态，避免在同段落中频繁切换
